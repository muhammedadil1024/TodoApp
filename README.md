# ToDo List App

![Demo App](/demo-todo.png)

A Simple ToDo List Application using React Js, But this is build file uploaded to GitHub.

### Features

* User can Add ToDo items list 
* User can remove when they want.
* When done, user can add or check the chekbox and added to Finished List

#### Technologies and Tools

- React Js
- Webpack
- GitHub Pages
